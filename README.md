# DevImpact Documentation

Welcome to the official documentation repository for **DevImpact**.

DevImpact is a GitHub-based digital ecosystem for organizing, documenting, and presenting software projects and developer resources. This repository explains the ecosystem's purpose, principles, governance, contribution expectations, security practices, and repository structure.

## Documentation scope

These documents describe the current GitHub-based structure and working practices. They do not claim that DevImpact is a legally incorporated company, and they do not create services, repositories, accounts, or infrastructure beyond the approved GitHub organization.

The organization is intentionally limited to five repositories:

1. `devimpact.github.io` — public main website.
2. `world-core` — private internal core.
3. `world-directory` — public project directory.
4. `world-docs` — public documentation.
5. `world-roadmap` — private planning.

Changes to this structure require explicit approval from the organization owner.

## Language

The documentation is written in English as the initial shared reference language. Additional translations may be added only when they are useful and approved.
